# Code of Conduct

## Our standard

We are committed to making participation in this project respectful,
constructive, and welcoming.

Unacceptable behavior includes harassment, discrimination, personal attacks,
publishing private information, deliberate disruption, and any conduct that
would be inappropriate in a professional community.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and
pull requests that violate this code. Repeated or serious violations may
result in a temporary or permanent ban from project spaces.

Report concerns privately to the repository owner through GitHub. All reports
will be reviewed as confidentially as practical.
